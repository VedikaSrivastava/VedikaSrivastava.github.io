# Vedika Srivastava Portfolio

Static GitHub Pages portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

The deployed site is static. Node is used only for local development and build tooling.

## Styling

- Tailwind CSS v4 drives layout, spacing, color, typography, shadows, and responsive behavior.
- Design tokens live in `src/styles/global.css`; components use utility classes instead of custom component CSS.
